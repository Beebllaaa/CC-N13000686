About this work

C — Toggle projection calibration
F — Fullscreen
S — Save projection mapping
L — Load saved mapping
P — Toggle mouse control mode
Mouse drag — Change the vanishing points of the tunnels when P mode is active

Process

My initial idea was to create an infinite square tunnel using simple geometric shapes. I wanted to explore how a flat animation could create a sense of depth when projected onto physical objects.
I started by using a for loop to draw squares of different sizes. Then I added an offset variable to make them move continuously. At first, the squares disappeared suddenly at the edges, so I used transparency to make the transition smoother.
Next, I experimented with controlling the vanishing point using the mouse. I used map() to convert the mouse position into coordinates for the tunnel. I also added a keyboard shortcut to turn this interaction on and off.
Another challenge was connecting the six projection surfaces. Instead of displaying exactly the same animation on every surface, I used a reverseX parameter to make the odd and even surfaces move in opposite horizontal directions while keeping the same vertical movement.
Finally, I experimented with color and light. I used lerpColor() to create a gradient from pink-purple on the outside to blue on the inside. By layering lines with different stroke weights and transparency, I created a soft glowing effect.
During the process, I also encountered coding problems, such as duplicated keyPressed() functions and placing drawing code inside setup() instead of draw(). Fixing these problems helped me better understand how different functions work together.
